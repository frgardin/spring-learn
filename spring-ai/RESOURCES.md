# Spring AI Resources

## Knowledge

- [Spring AI Official Documentation](https://docs.spring.io/spring-ai/reference/index.html)
  Comprehensive reference for Spring AI features, APIs, and examples. Use for: all Spring AI concepts, API usage, configuration.

- [Spring AI GitHub Repository](https://github.com/spring-projects/spring-ai)
  Source code, examples, and community contributions. Use for: code examples, implementation details, issue tracking.

- [Spring AI Getting Started Guide](https://docs.spring.io/spring-ai/reference/getting-started.html)
  Step-by-step guide to create your first Spring AI application. Use for: initial setup, basic configuration, first chatbot.

- [Spring AI Chat Client API](https://docs.spring.io/spring-ai/reference/api/chatclient.html)
  Fluent API for communicating with AI Chat Models. Use for: building chat interfaces, handling conversations, streaming responses.

- [Spring AI Concepts](https://docs.spring.io/spring-ai/reference/concepts.html)
  High-level overview of AI concepts and their representation in Spring AI. Use for: understanding core terminology, architecture.

- [Spring AI OpenAI Integration](https://docs.spring.io/spring-ai/reference/api/chat/openai-chat.html)
  Specific documentation for OpenAI chat models integration. Use for: OpenAI configuration, model selection, API keys.

- [Spring AI Advisors API](https://docs.spring.io/spring-ai/reference/api/advisors.html)
  Encapsulates recurring Generative AI patterns. Use for: implementing common AI patterns, data transformation, portability.

- [Spring AI Tool Calling](https://docs.spring.io/spring-ai/reference/api/tools.html)
  Permits model to request execution of client-side tools. Use for: enabling real-time information access, function execution.

## Wisdom (Communities)

- [Spring AI Community on GitHub](https://github.com/spring-projects/spring-ai/discussions)
  Official discussion forum for Spring AI. Use for: asking questions, sharing implementations, getting community help.

- [Stack Overflow - Spring AI Tag](https://stackoverflow.com/questions/tagged/spring-ai)
  Q&A platform for Spring AI related issues. Use for: troubleshooting, specific implementation questions.

- [Spring Community Slack](https://spring.io/community/slack)
  Real-time chat with Spring developers. Use for: quick questions, networking, staying updated.
