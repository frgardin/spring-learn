# Spring AI Learning Workspace

Welcome to your Spring AI learning journey! This workspace is designed to help you build an educational chatbot using Spring AI.

## Getting Started

1. **Read the Mission**: Start with [MISSION.md](MISSION.md) to understand your learning goals
2. **Check Resources**: Review [RESOURCES.md](RESOURCES.md) for trusted learning materials
3. **Start Learning**: Begin with [Lesson 1: Setting Up Your First Spring AI Chatbot](lessons/0001-setup-first-chatbot.html)
4. **Continue Learning**: [Lesson 2: Adding Conversation Memory](lessons/0002-conversation-memory.html)
5. **Continue Learning**: [Lesson 3: Streaming Responses](lessons/0003-streaming-responses.html)
6. **Continue Learning**: [Lesson 4: Tool Calling](lessons/0004-tool-calling.html)

## How to Use

1. **Open Lessons**: Open the HTML files in your browser to view interactive lessons
2. **Complete Exercises**: Each lesson includes hands-on exercises
3. **Ask Questions**: Your teacher (AI assistant) can help with any concepts
4. **Track Progress**: Check learning-records to see what you've learned
