Lesson 2: Adding Conversation Memory to Your Chatbot

Mission Connection: Adding conversation memory will make your educational chatbot more effective by allowing it to remember previous interactions and provide contextual responses.

What You'll Learn

  • Why conversation memory is important for educational chatbots
  • How Spring AI implements chat memory
  • Configuring memory with MessageWindowChatMemory
  • Using conversation IDs to manage different conversations
  • Testing memory in your chatbot

Why Conversation Memory Matters

Without memory, each interaction with an AI model is independent. For an educational chatbot, this means:

  • The bot can't remember what topics you've covered
  • It can't build on previous explanations
  • Each conversation starts from scratch
Educational Benefit: With memory, your chatbot can:
  • Remember what concepts you've already learned
  • Avoid repeating explanations
  • Build on previous knowledge
  • Provide personalized learning paths

Step 1: Understanding Spring AI Memory

Spring AI provides two key abstractions:

  • ChatMemory - Manages which messages to keep and when to remove them
  • ChatMemoryRepository - Stores and retrieves messages

The default implementation uses:

  • InMemoryChatMemoryRepository - Stores messages in memory
  • MessageWindowChatMemory - Keeps a sliding window of messages

Step 2: Update Your Chat Controller

Let's modify the chat controller from Lesson 1 to include memory. Update ChatController.java:

package com.example.chatbot;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.client.advisor.MessageChatMemoryAdvisor;
import org.springframework.ai.chat.memory.ChatMemory;
import org.springframework.ai.chat.memory.MessageWindowChatMemory;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/chat")
public class ChatController {
    
    private final ChatClient chatClient;
    private final ChatMemory chatMemory;
    
    public ChatController(ChatClient.Builder builder) {
        this.chatMemory = MessageWindowChatMemory.builder()
            .maxMessages(10)  // Keep last 10 messages
            .build();
        
        this.chatClient = builder
            .defaultAdvisors(MessageChatMemoryAdvisor.builder(chatMemory).build())
            .build();
    }
    
    @GetMapping("/simple")
    public String simpleChat(@RequestParam String message) {
        return chatClient.prompt(message).call().content();
    }
    
    @GetMapping("/with-memory")
    public String chatWithMemory(
            @RequestParam String message,
            @RequestParam(defaultValue = "user123") String conversationId) {
        
        return chatClient.prompt()
            .user(message)
            .advisors(a -> a.param(ChatMemory.CONVERSATION_ID, conversationId))
            .call()
            .content();
    }
}

Step 3: Test Memory Functionality

Run your application and test these scenarios:

  1. First request: 
    curl "http://localhost:8080/api/chat/with-memory?message=My+name+is+Alex&conversationId=student1"
  2. Second request (same conversation): 
    curl "http://localhost:8080/api/chat/with-memory?message=What+is+my+name?&conversationId=student1"
  3. Third request (different conversation): 
    curl "http://localhost:8080/api/chat/with-memory?message=What+is+my+name?&conversationId=student2"
Expected Results:
  • Request 2 should remember "Alex" from the same conversation
  • Request 3 should not know the name (different conversation ID)

Understanding the Code

Key Concepts:
  • MessageWindowChatMemory.builder().maxMessages(10) - Keeps last 10 messages
  • MessageChatMemoryAdvisor - Advisor that manages conversation memory
  • ChatMemory.CONVERSATION_ID - Parameter to identify different conversations
  • advisors(a -> a.param(...)) - Sets the conversation ID for each request
  • defaultAdvisors - Sets default advisors for all requests

Memory Configuration Options

Option Description Default
maxMessages Maximum messages to keep in memory 20
chatMemoryRepository Storage implementation InMemoryChatMemoryRepository
