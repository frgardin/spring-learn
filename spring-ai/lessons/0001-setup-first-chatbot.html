Lesson 1: Setting Up Your First Spring AI Chatbot

Mission Connection: This lesson starts your journey to build an educational tutor chatbot using Spring AI.

What You'll Learn

  • How to create a Spring Boot application with Spring AI dependencies
  • Basic configuration for OpenAI integration
  • Creating a simple chat endpoint
  • Testing your first AI conversation

Prerequisites

  • Java 17 or later
  • Maven or Gradle
  • OpenAI API key (get from platform.openai.com)

Step 1: Create Spring Boot Project

Use Spring Initializr with these dependencies:

  • Spring Web - For REST endpoints
  • Spring AI OpenAI - For AI integration

Step 2: Configure Application Properties

Add your OpenAI API key to src/main/resources/application.properties:

# OpenAI Configuration
spring.ai.openai.api-key=${OPENAI_API_KEY}
spring.ai.openai.chat.options.model=gpt-3.5-turbo

# Server Configuration
server.port=8080
Security Note: Never commit API keys to version control. Use environment variables or Spring Cloud Config for production.

Step 3: Create Chat Controller

Create a REST controller in src/main/java/com/example/chatbot/ChatController.java:

package com.example.chatbot;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/chat")
public class ChatController {
    
    private final ChatClient chatClient;
    
    public ChatController(ChatClient.Builder builder) {
        this.chatClient = builder.build();
    }
    
    @GetMapping("/simple")
    public String simpleChat(@RequestParam String message) {
        return chatClient.prompt(message).call().content();
    }
}

Step 4: Test Your Chatbot

  1. Run the application: ./mvnw spring-boot:run
  2. Test with curl or browser: 
    curl "http://localhost:8080/api/chat/simple?message=Hello%20Spring%20AI"
  3. You should get a response from the AI model

Understanding the Code

Let's break down what's happening:

Key Concepts:
  • ChatClient.Builder - Spring AI's fluent API for building chat clients
  • prompt(message) - Creates a prompt with your message
  • call() - Executes the prompt synchronously
  • content() - Extracts the text response

Quiz: Test Your Understanding

What annotation is used to mark a class as a REST controller in Spring?
  • @RestController
  • @Controller
  • @Service
What method executes a prompt synchronously in Spring AI?
  • execute()
  • run()
  • call()
