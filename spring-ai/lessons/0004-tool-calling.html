Lesson 4: Adding Tool Calling to Your Educational Chatbot

Mission Connection: Tool calling enables your educational chatbot to access external tools like calculators, dictionaries, or educational APIs, making it more interactive and accurate.

What You'll Learn

  • Why tool calling is important for educational chatbots
  • How to define tools using @Tool annotation
  • Passing tools to ChatClient
  • Understanding the tool calling loop
  • Testing tools in your chatbot

Why Tool Calling Matters

Without tools, your chatbot can only generate text based on its training data. For an educational chatbot, this means:

  • It can't perform calculations (math problems)
  • It can't look up current information (weather, news)
  • It can't access external educational resources
  • It can't execute actions (send emails, update records)
Educational Benefits:
  • Interactive learning - Students can ask for calculations, definitions, or examples
  • Real-time information - Access to current data for up-to-date explanations
  • Practical applications - Demonstrate concepts with real tools
  • Enhanced engagement - More dynamic and responsive conversations

Step 1: Understanding Tool Calling in Spring AI

Spring AI provides a powerful tool calling system that allows AI models to request execution of client-side tools. The flow is:

  1. You define tools (methods annotated with @Tool)
  2. Pass tools to ChatClient
  3. AI model decides when to call tools based on user queries
  4. Spring AI executes the tools and returns results to the model
  5. Model continues the conversation with tool results
Security Note: Tools are executed on your server, not by the AI model. The model only sends tool call requests; your application controls execution.

Step 2: Create Educational Tools

Create a new class EducationalTools.java in your project:

package com.example.chatbot.tools;

import org.springframework.ai.tool.annotation.Tool;
import org.springframework.ai.tool.annotation.ToolParam;

import java.util.Map;

public class EducationalTools {

    @Tool(description = "Calculate mathematical expressions")
    public String calculate(@ToolParam(description = "Mathematical expression to evaluate") String expression) {
        try {
            // Simple expression evaluator (in production, use a proper library)
            double result = evaluateExpression(expression);
            return String.format("Result of %s = %.2f", expression, result);
        } catch (Exception e) {
            return "Error: Could not evaluate expression '" + expression + "'";
        }
    }

    @Tool(description = "Get definition of a word")
    public String getDefinition(@ToolParam(description = "Word to define") String word) {
        // Mock dictionary - in real app, call a dictionary API
        Map<String, String> dictionary = Map.of(
            "algorithm", "A step-by-step procedure for solving a problem",
            "variable", "A symbol representing a value that can change",
            "function", "A block of code that performs a specific task"
        );
        
        String definition = dictionary.getOrDefault(word.toLowerCase(), 
            "Definition not found. Try asking for: algorithm, variable, or function");
        
        return String.format("%s: %s", word, definition);
    }

    @Tool(description = "Get educational fact about a topic")
    public String getEducationalFact(@ToolParam(description = "Topic to get fact about") String topic) {
        // Mock educational facts - in real app, call an educational API
        Map<String, String> facts = Map.of(
            "math", "Mathematics is the study of numbers, shapes, and patterns",
            "science", "Science is the systematic study of the natural world",
            "programming", "Programming is the process of creating instructions for computers"
        );
        
        String fact = facts.getOrDefault(topic.toLowerCase(), 
            "Interesting fact: Learning is a lifelong journey!");
        
        return String.format("About %s: %s", topic, fact);
    }

    private double evaluateExpression(String expression) {
        // Simple evaluation - in production use exp4j or similar library
        // This is a mock implementation
        try {
            return Double.parseDouble(expression.replaceAll("[^0-9.+-*/()]", ""));
        } catch (NumberFormatException e) {
            // For demo purposes, return a random result
            return Math.random() * 100;
        }
    }
}

Step 3: Update Your Chat Service

Modify your ChatService.java to include tools:

package com.example.chatbot.service;

import com.example.chatbot.tools.EducationalTools;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.stereotype.Service;

@Service
public class ChatService {
    
    private final ChatClient chatClient;
    private final EducationalTools educationalTools;
    
    public ChatService(ChatClient.Builder builder) {
        this.chatClient = builder.build();
        this.educationalTools = new EducationalTools();
    }
    
    public String simpleChat(String message) {
        return chatClient.prompt(message).call().content();
    }
    
    public String chatWithTools(String message) {
        return chatClient.prompt(message)
            .tools(educationalTools)
            .call()
            .content();
    }
}

Step 4: Update Your Controller

Add a new endpoint for tool-enabled chat in ChatController.java:

@GetMapping("/with-tools")
public String chatWithTools(@RequestParam String message) {
    return chatService.chatWithTools(message);
}

Understanding the Code

Key Concepts:
  • @Tool annotation - Marks a method as a tool the AI can call
  • @ToolParam annotation - Describes tool parameters for the AI
  • description parameter - Tells the AI when to use the tool
  • .tools() - Passes tools to ChatClient for a specific request
  • ToolCallingAdvisor - Auto-registered advisor that handles the tool loop

Tool Calling Flow

When you ask "What is 123 * 456?", here's what happens:

  1. Your request goes to the AI model with tool definitions
  2. AI recognizes this is a math problem and needs the calculator tool
  3. AI sends a tool call request: calculate("123 * 456")
  4. Spring AI executes the tool on your server
  5. Tool result is sent back to the AI model
  6. AI uses the result to generate a response like "123 * 456 = 56,088"

Best Practices for Educational Tools

Practice Description
Clear descriptions Write tool descriptions that help the AI know when to use them
Error handling Always handle exceptions gracefully in tools
Input validation Validate tool parameters to prevent security issues
Return meaningful results Format tool results so the AI can use them effectively
